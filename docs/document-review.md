# ドキュメントの構成

| 文書 | 内容 |
| --- | --- |
| `README.md` | 配布概要、ダウンロード、導入の入口 |
| `CHANGELOG.md` | リリースごとの追加機能・変更内容 |
| `docs/server-setup.md` | サーバー導入、認証、既存ワールドの移行 |
| `docs/coasters-recipes.md` | Coastersの素材、クラフト方法、JEI検索 |
| `docs/development.md` | ビルド入力、固定ツール、テストとCI |
| `docs/publishing.md` | 提出、審査、Server Pack区分、公開確認 |
| `docs/mod-update-0.0.3.md` | 0.0.3の固定参照と依存制約の技術レビュー |
| `docs/create-addons-0.0.4.md` | 0.0.4の追加MODと依存制約の技術レビュー |
| `docs/release-history.md` | 公開・移行・調査の履歴資料 |

利用案内とCHANGELOGには現在の機能と操作を記載します。検証結果や作業経緯は履歴・技術レビュー資料に記載します。第三者MODの設定READMEとライセンス条文は原文を保持します。
